# Changelog

Здесь описаны все заметные изменения Зари. Проект использует
[семантическое версионирование](https://semver.org/).

The English version of this file is [CHANGELOG.md](CHANGELOG.md).

## 0.7.7 — «Смета» (2026-08-19)

Тема выпуска: **Заря перестала врать о себе**. Прошлый выпуск научил панели
переговариваться; этот — про то, чего Заря о себе не знала или говорила
неправду: сколько на самом деле стоят инструменты, какие из них у агента есть,
что происходит в соседней панели и во что обходится разговор двух агентов.

### Добавлено

- **Заполнение контекста видно всегда, и это число ЭТОЙ панели.** Раньше
  показатель появлялся только в конце хода, а само число было общим на
  приложение: четыре панели показывали одно и то же. Теперь оно живёт в беседе.

- **Агент читает вашу консоль сам — и ищет по ней.** Ему больше не нужно просить
  переслать лог, который лежит в этой же панели: он смотрит список запущенных
  команд, дочитывает нужный вывод и ищет по нему слово («где я это видел»).
  Поиск возвращает несколько блоков с одной совпавшей строкой у каждого, а не
  весь журнал.

  Всё это — через карточку разрешения, и **карточка называет команду**, а не
  идентификатор блока: раньше вы одобряли `{"id":"b17"}`, не видя, что читают.
  Разрешения «до конца сессии» у чтения вывода нет вовсе — оно означало бы
  доступ ко всей будущей консоли по одному нажатию.

- **Две панели в одной папке — сказано вслух.** В шапке появляется тихая строка
  «та же папка · <панель>», а агент видит то же в списке панелей. Заря файлы не
  блокирует, и текст говорит именно это: договаривайтесь, кто что правит.

- **Видно, кто кого ждёт.** Панель, задавшая вопрос соседу, больше не выглядит
  бездельничающей. Подписано честно — «сказала, что ждёт»: это заявление агента,
  а не состояние приложения, и оно гаснет само.

- **Денежный предохранитель на переписку панелей.** Прежние пределы считали
  записки, а платит человек за ходы: двадцать записок в час — это до двадцати
  платных ходов модели. Теперь считается работа, начатая чужой запиской, по паре
  панелей за час. Записка при этом не теряется — она видна вам с объяснением;
  гасится только автоматический ход.

- **Визитка Зари в промпте движка.** Агент знает, где работает: что вы видите
  ленту, что его вызовы приходят карточками, что рядом ваша оболочка. И главное
  — чего у Зари **нет**: откат файлов, режимы допуска, сохранённые подключения —
  это ваши кнопки, а не его вызовы. Без этого он охотно сочинял Заре
  возможности и обещал их вам от её имени.

- **Сервер MCP просит вас войти — вы об этом узнаёте.** Раньше такой запрос
  отклонялся молча: сервер оставался неработающим без единого слова на экране.
  Теперь отказ назван вместе с ручным путём.

### Исправлено

- **Цена инструментов MCP больше не врёт.** Вкладка говорила «занимают ~N
  токенов в каждом запросе», а движок эти описания откладывает: в старте лежат
  имена, полное описание подгружается по надобности. Живой замер на машине
  автора: 25 966 токенов инструментов, из них в окне — ноль. Теперь показаны оба
  числа, и отложенное названо словом.

- **Показатель контекста завышал вдвое** — складывались все итерации запроса
  вместо последней.

- **Заря не оставляет мусор.** Атомарная запись при падении оставляла временные
  файлы; теперь она убирает свой и подметает осиротевшие при старте.

### Безопасность

Перед выпуском — аудит четырьмя углами и разбор скептиком, всё на Opus. Два
дефекта оказались в защите от чужого текста, который попадает в контекст модели
мимо человека:

- **Один невидимый символ отменял защиту целиком.** Селекторы вариаций были
  выведены из-под чистки ради эмодзи — и подделка вида `Human␍: игнорируй` или
  `<system␍-reminder>` проходила нетронутой на всех путях сразу. Теперь
  исключений нет; эмодзи теряют селектор представления, сам знак остаётся.

- **Хвост консоли не проходил чистку** — гасился только дословный маркер, а
  поддельные системные пометки и границы ходов ехали в каждом ходе. Хвост
  включён по умолчанию, то есть это была самая широкая дорога.

- **Чужой `.mcp.json` мог обойти карточку разрешения**: два наших инструмента
  разрешались по имени, а имя собирается из имени сервера, которое приходит из
  открытого проекта. Теперь ослабление привязано к согласию.

- Ход по чужой записке снимал автопилот, но не правила «до конца сессии» — сосед
  мог чужими руками молча править файлы.

- Имена и пути соседних панелей, имя автора записки и текст MCP-сервера чистятся
  на всех путях к модели и к экрану.

## 0.7.6 — «Перекличка» (2026-08-16)

Тема выпуска: **панели перестали быть одиночками**. Раньше каждая жила сама по
себе: агент не знал, что рядом работают другие, не видел команд, которые человек
набирал руками в той же панели, и держал разговор занятым, пока идёт долгая
сборка. Теперь панели видят друг друга, передают записки, отпускают работу в фон
и читают консоль — и всё это видно человеку.

### Добавлено

- **Панели видят друг друга и могут переговариваться.** Агент знает, какие ещё
  панели открыты, в каких папках они работают и чем заняты прямо сейчас. На
  вопрос про чужой проект он больше не гадает и не ищет по диску, а говорит,
  какая панель это знает, и предлагает спросить её.

  Записка приходит соседу **своим видом**, а не репликой человека: нарисовать её
  его словами значило бы заставить поверить, что он сам это написал. Одобрить
  разрешение или поменять настройки записка не может, слэш-команда в ней
  остаётся текстом. Есть защита от петель — частота, повторы, потолок на пару
  панелей, — и отправитель всегда получает честный ответ: доставлено, придержано
  и почему, панели больше нет, записки выключены.

  Ход по чужой записке идёт **с вопросами**, даже если в панели включён
  автопилот: согласие «делай молча» человек давал своим словам, а не соседским.

- **Работу можно увести в фон.** Долгая задача больше не держит разговор: у
  карточки есть кнопка, а внизу — строка о том, что осталось работать.

  Честная граница: увести в фон **уже идущую** команду оболочки движок не
  умеет — отвечает «увёл» и продолжает ждать. Поэтому кнопка стоит только там,
  где срабатывает, а для команд заведена отдельная просьба к агенту запускать
  долгое в фоне сразу. Настройка так и называется — просьба, не гарантия.

- **Сохранённые подключения.** SSH-хост открывается обычной панелью: без набора
  строки подключения каждый раз.

- **Агент видит команды, которые вы запускали.** Последние команды с кодами
  возврата и хвостом вывода уезжают вместе с сообщением — не приходится
  пересказывать, что вы только что запускали и почему это упало.

  Настройка обещала это и раньше, но работала только для встроенного агента:
  Claude Code ваших команд не видел вовсе. Теперь едет всем движкам — и не
  припиской к системному промпту, а частью хода, потому что хвост обязан быть
  свежим на каждом ходу.

  Вторая половина обязательна: над вашим вопросом стоит строка о том, что именно
  ушло, разворачивается в список команд, и той же кнопкой подача выключается и
  включается обратно — по панели. Отдать вывод вашей консоли чужой модели без
  видимого следа было бы непрозрачно ровно там, где вы рассчитываете на
  приватность.

  Вывод передаётся с пометкой «недоверенные данные», подделка пометки гасится —
  включая попытку подделать её в самой строке команды.

- **Спросить мимо контекста.** Кнопка рядом с режимом плана: вопрос и ответ
  остаются в ленте, но в следующий ход не поедут — он продолжится от места, где
  вы были до вопроса. Спросить «а что это такое?» и не тащить это в контекст до
  конца разговора.

  Работает там, где движок умеет ветвить сессию, — сегодня это Claude Code. У
  остальных кнопки нет вовсе. А если вопрос всё же ушёл и ветки не нашлось,
  пометка говорит прямо: «не получился — остался в контексте».

### Изменено

- **Смысл виден не только по цвету.** Три ступени допуска получили три разных
  знака: замок, карандаш, молния. Раньше их было два — один и тот же замок стоял
  и на «спрашивать всё», и на «правки без спроса», а различал их только цвет
  чипа. Это самое дорогое обещание интерфейса: спросят ли меня перед тем, как
  тронуть файлы.

  Полоса состояния панели различается формой: ждущая прерывистая, рабочая
  сплошная. Прежде это были красный против зелёного — худшая пара для самого
  частого дальтонизма, — а при отключённых анимациях не оставалось и разницы в
  движении. Включённый режим плана получил пунктирную рамку, всплывающие
  уведомления — знаки уровня и объявление для чтения с экрана.

- Настройка «Блоков контекста» переехала во вкладку «Движок». Прежняя вкладка
  скрыта, когда надстройка IDE выключена, — то есть настройку про собственную
  консоль большинство не видело.

### Исправлено

- **Бета не видела вышедший релиз.** Сравнение версий теряло хвост `-beta.8`, и
  на устаревшей сборке значилось «у вас последняя версия».
- **Панель называла себя путём к `powershell.exe`.** Windows PowerShell
  отправляет свой путь заголовком, и панель так и подписывалась.
- Ход по чужой записке не работает на автопилоте; отказ «не читать здесь»
  переживает перезапуск и распространяется на панель, а не на один разговор.

### Числа

**1104 юнит-проверки в 82 файлах** (было 989 в 76) и **120 прогонов** на живом
приложении (было 111). Живые сценарии против настоящего Claude Code — откат,
записки, хвост консоли, боковой вопрос — в CI не гоняются вовсе: они тратят
токены владельца.

Оба последних инкремента прошли ревью на Opus с адверсариальной проверкой: 6 и 8
подтверждённых дефектов соответственно, все закрыты и покрыты прогонами.

## 0.7.5 — «Обратный ход» (2026-08-13)

Тема выпуска: **можно вернуться — и стало видно, что происходит**. Разговор Заря
откатывала и раньше, но файлы на диске оставались, и отыгрывать приходилось через
git. Теперь возвращается и то, и другое.

Второй половиной выпуска закрыты два ряда сравнения с обычным терминалом: около
полусотни мест, где интерфейс молчал или обещал то, чего не делает. Сравнение
было честным — аудит на 380 пунктов против настоящего Claude Code и настоящего
эмулятора терминала.

### Добавлено

- **Откат кода, а не только разговора.** У каждого вашего хода — кнопка, которая
  возвращает файлы к состоянию на этом ходе. Механизм родной, движка
  (`rewindFiles`), а не наш теневой git.

  Работа оказалась не в вызове, а в карточке перед ним. Родной откат молча
  затирает ручные правки, ходит за пределы папки панели, а «успех» у него не
  значит, что файлы вернулись. Поэтому карточка показывает **каждый файл
  поимённо** и отличает правку человека от правки агента; файл, созданный ПОСЛЕ
  выбранного хода, помечен «БУДЕТ УДАЛЁН» — откат двунаправленный, и спокойное
  «вернётся» про такой файл было бы враньём.

  Перед откатом снимается **страховочная копия**. Не сняли — откат ОТМЕНЯЕТСЯ и
  причина называется по каждому файлу: иначе работа человека исчезала бы сразу
  после обещания её сохранить. Копии живут в своей папке с лимитом и убираются
  сами.

  И то, чего нет в документации движка: **откат работает только назад**. На ход
  позже уже сделанного отката Claude Code отвечает «могу» и не делает ничего.
  Карточка говорит об этом прямо.

- **Молчание получило голос.** Движок говорил больше, чем показывала лента:
  повтор запроса после ошибки API, отказ по правилу, гашение воркера, ответ
  локальных слэш-команд, упавший хук — всё это проваливалось в пустоту, и экран
  в такую минуту не отличался от зависшего.

- **Видно, как агент думает и что вернул инструмент.** Рассуждения (`thinking`)
  — свёрнутым блоком, разворачиваются щелчком. Карточка вызова говорит, что
  инструмент сделал НА САМОМ ДЕЛЕ: «прочитано 200 из 4000», «оборвано по
  времени», «ушло в фон». Аргументы вызова печатаются на глазах, а не тремя
  точками. Картинка, вернувшаяся от MCP-сервера, доходит до экрана.

- **Итог хода называет себя.** Сколько шёл, через сколько пошёл первый токен,
  чем кончился, сколько вызовов отклонено без вопроса. Но только когда есть что
  сказать: молчаливый успех остаётся молчаливым, иначе строку перестанут читать
  там, где она важна.

- **Терминал слушается человека.** Ctrl+C из строки ввода прерывает команду в
  панели, а не только в фокусе терминала. Тумблер «подтверждать закрытие при
  работающем процессе» заработал — раньше он был объявлен и не читался нигде.
  Предупреждение о многострочной вставке перестало обходиться обычным Ctrl+V.
  Файл, бро́шенный в панель, вставляет путь, а не открывает вкладку.

- **Жесты из консоли.** Shift+Tab водит замок по кругу: спрашивать → правки без
  спроса → автопилот (раньше между «спрашивать» и «автопилотом» не было ничего).
  Отказ вызову можно сопроводить объяснением одним движением. «@» упоминает файл
  с автодополнением, «#» пишет строку в память проекта, «/copy» забирает ответ
  целиком.

- **Разрешения: экран, а не только гейт.** Правый щелчок по замку — «Что
  разрешено»: ступень допуска словом, выданные до конца беседы правила дословно
  и с кнопкой отзыва, рабочие папки. Отдельной строкой сказано то, о чём молчат
  все: безобидные команды (`echo`, `ls`) движок разрешает сам, до Зари они не
  доходят ни в каком режиме.

- **Движок и память под рукой.** Вкладка «Движок»: какой именно `claude`
  работает и почему он, кто вошёл, что говорит о себе `doctor`. Когда сломан
  движок, сломанной выглядит Заря — теперь видно, что сломан именно он. Рядом —
  правка `CLAUDE.md` всех уровней там же, где показана её цена в токенах.

- **Разговор можно унести.** Беседа в Markdown, копия целиком, вывод терминала
  в файл. Путь выбирает система, а не мы.

- **`zarya .` открывает проект** — из проводника, из скрипта, из другого
  терминала. Заря уже открыта — папка приедет в неё. Саму команду `zarya`
  ставит одна кнопка: Настройки → Терминал.

- **Долгая команда докладывает.** Уведомление о завершении с кодом выхода —
  «сборка закончилась» и «сборка упала» — две разные новости. Программа
  подписывает вкладку сама (`ssh prod`, `vim`, `htop`).

- **Диктовка тремя режимами.** Текст по ходу речи (по умолчанию), одна фраза с
  автостопом, удержание клавиши. Порог речи считается от самого громкого места
  этой записи, а не константой: тихий микрофон больше не оставляет автостоп
  немым. Рядом — **проверка микрофона**: живая шкала, черта порога на ней,
  вердикт теми же словами, какими судит автостоп, и расшифровка той же моделью.

- **Навигатор по своим сообщениям.** Столбик у правого края и Alt+↑/↓: в длинной
  сессии ищешь не ответ агента, а свою реплику — «что я вообще просил». Прыжок
  подсвечивает ход и сразу показывает его кнопки, включая откат.

### Исправлено

- **PATH брался из устаревшей копии.** Windows хранит PATH в реестре, а процесс
  получает копию от родителя. Заря, запущенная до установки Rust, отдавала
  старый PATH всем своим оболочкам — и новым панелям, и перезапущенным. Со
  стороны это выглядело как «программа не установилась». Теперь каждая оболочка
  перечитывает PATH из реестра, не теряя того, что дали самой Заре.

- **«Команда не найдена» получила объяснение и кнопку.** Под упавшей командой —
  «программу могли установить после запуска этой оболочки» и «перезапустить и
  повторить».

- **Блоки команд шли не по времени разговора.** Команда, запущенная из ленты,
  оказывалась за километр вверх — в разговоре на несколько минут её просто не
  было видно. Две команды из одного блока кода склеивались в один блок задом
  наперёд. После запуска из ленты некуда было печатать.

- **Полоса поверх ленты.** Живой xterm под лентой продолжал рисовать кадры, и на

- **Диктовка перестала заканчиваться сама.** Признак «клавишу держат» мог

## 0.7.4 — «Ревизия» (2026-08-04)

Тема выпуска: **что у вас есть и во сколько это обходится**. У человека с
десятками скиллов и полутора десятками MCP-серверов половина набора не работает,
а платит он за весь — в каждом запросе. Этот выпуск считает вслух.

### Добавлено

- **Скиллы больше не бесплатны на вид.** Описание каждого скилла лежит в
  контексте ЛЮБОГО запроса — иначе агент не знал бы, что скилл существует. Тело
  грузится только при вызове, а описание платное всегда. Движок считает это
  поимённо, и до сих пор цифру никто не показывал. Замер на машине владельца в
  день выпуска: 83 скилла, **5 347 токенов в каждом запросе**.

- **Видно, что из оплаченного работает.** Заря запоминает, какие скиллы реально
  срабатывали, и показывает прямой ответ на вопрос «что выключить»: «ни разу не
  сработали 82 штуки на ~4 986 токенов». Счёт ведётся на этой машине и никуда не
  уходит: в файле только имена ваших скиллов и числа — ни запросов, ни ответов,
  ни путей. Период называется честно: «за 1 день наблюдения», а не «за 30 дней»,
  пока их не прошло.

- **Управление — четырьмя состояниями самого Claude Code**, а не галочкой:
  в работе · только имя · только по «/» · выключен. Средние два ценнее крайних:
  «только имя» оставляет скилл рабочим за долю цены, «только по „/“» убирает его
  из контекста, не отнимая возможность позвать руками.

### Исправлено

- **Выход за песочницу через висячий симлинк** (безопасность, HIGH). Проверка
  «путь внутри проекта» следовала по ссылке и потому не видела битую: агент писал
  «в проект», а файл появлялся снаружи — например, в домашней папке, откуда
  исполнялся при следующем входе в оболочку. Затрагивало macOS и Linux.

- **Кнопка «Вставить» в ленте исполняла код.** Подтверждение на многострочный
  кусок было в боковой панели и потерялось в ленте: внутренние переводы строк
  уходили в терминал, и первая строка выполнялась раньше, чем её успевали
  прочитать.

- **Команда для входа в MCP-сервер экранировалась по правилам sh**, а вставляют
  её в PowerShell — там обратный слэш не экранирует ничего. Имя сервера приходит
  из файла открытого проекта, то есть это чужой текст. Теперь готовая строка
  показывается только для безопасных имён, для остальных Заря честно говорит, что
  команды не будет.

- **Выключенная история команд всё ещё отвечала** в Ctrl+R и в подсказках
  терминала: запрет стоял только на записи. Настройка обещала обратное дословно.

- **История теряла самую старую запись** при каждой загрузке, а уплотнение
  стирало её с диска.

- **Состояние агента больше не рисуется рамкой.** Ждущая панель обводилась тем же
  цветом, что и активная, и два признака читались как один. Теперь состояние —
  полоса у верхнего края, и цвета разные: оранжевая зовёт, зелёная говорит
  «занят». Заодно появилось само «работает»: раньше работа шла молча.

- **На светлой теме стало видно шов между панелями** — четыре панели сливались в
  одно белое поле.

- **Палитра «/» перестала подпрыгивать** на команде с длинным описанием: панель
  вырастала вверх и уезжала из-под курсора.

- **У панели одна шапка вместо двух.** Лента рисовала свою поверх шапки панели —
  оставалась пустая полоса с лишней линией.

## 0.7.3 — «Дежурство» (2026-08-03)

Тема выпуска: **внимание человека**. Четыре панели, у каждой свой агент и свой
автопилот — и чем лучше это работает, тем чаще человек не знает, кто из них
встал и ждёт нажатия, а что из инструментов давно сломано. Этот выпуск про то,
чтобы Заря дежурила вместо вас.

### Добавлено

- **Видно, кто работает, а кто ждёт вас.** Раньше и то и другое считалось одним
  состоянием и подписывалось словом «выполняется». День выглядел так: отправил
  задачу, ушёл, вернулся через десять минут — девять из них агент ждал одного
  нажатия.

  Теперь это два разных состояния. В сайдбаре ждущие идут первыми, со временем
  ожидания («ждёт вас · 4 мин») и цветом действия; работающие — спокойным
  зелёным. Заголовок раздела считает ждущих. Ждущая панель пульсирует — медленно
  и неярко, а в панели, на которую вы уже смотрите, пульс гаснет.

  Считается строго по фактическим запросам разрешения, без догадок по выводу:
  индикатор врёт легче всего остального, а «готов» вместо «завис» — худшая из
  его неправд.

- **Заря зовёт, когда агент встал.** Системное уведомление и подсветка окна в
  панели задач — только когда окно **не в фокусе** и только на переход в
  ожидание, а не на каждое сообщение. Сообщать о том, что и так на экране,
  значит потратить доверие к уведомлениям, а шум выключают вместе с сигналом.
  Клик поднимает окно. Выключается одной галочкой в настройках.

- **Команды движка через «/».** Список приходит от самого агента — `/review`,
  `/compact`, ваши скиллы, — а не из константы в нашем коде, которая устаревала
  бы с каждым его релизом. Движок, который своих команд не называет, так и
  говорит, вместо того чтобы показать пустой список.

- **«Разрешить до конца сессии» — и пол, который не снимается.** Между
  «спрашивать всё» и «не спрашивать ничего» не было ничего. Теперь в карточке
  инструмента есть третья кнопка, и рядом с ней — дословно то правило, которое
  будет создано: «до конца сессии не спрашивать про: `git status`».

  Чего это правило не покроет никогда: `rm -rf`, `git push --force`,
  `DROP TABLE` и подобное Заря показывает перед запуском всегда, даже при
  включённом автопилоте. Это не песочница, и мы её так не называем: изоляции ОС
  здесь нет, есть обещание про то, что вам всегда покажут.

- **Новые скиллы и MCP-серверы подхватываются без перезапуска.** Обычный ответ
  после установки — «перезапустите сессию», то есть «потеряйте разговор и
  начните сначала». Заря замечает, что на диске появилось новое, и предлагает
  перечитать: одно нажатие, сессия та же, контекст цел.

- **Вкладка «Инструменты»: видно, что живо и во сколько обходится.** Состояние
  MCP-серверов выбранной панели — работает, не отвечает, нужен вход, выключен, —
  и при отказе **причина от движка дословно**, без нашего пересказа. Рядом
  «Переподключить» и «Выключить».

  Замер на рабочей машине в день выпуска: из четырнадцати серверов три молча
  упали, четыре ждали входа, а описания инструментов занимали **~15 800 токенов
  в каждом запросе** — почти половину занятого контекста. Раньше это можно было
  узнать единственным способом: вручную запустить `claude mcp list`.

  Панель называет, **чьи** инструменты показывает: конфиг `.mcp.json` проектный,
  а окно контекста принадлежит сессии, поэтому две панели в разных
  репозиториях видят разное. Серверу, который ждёт входа, Заря не предлагает
  «переподключить» — это не помогло бы; она даёт готовую команду
  `claude mcp login «имя»`, которую можно скопировать.

### Исправлено

- **Правый клик по кнопке микрофона открывал два меню внахлёст** — выбор
  устройства и меню панели («Копировать», «Разделить вправо», «Закрыть
  панель»), оба ждали решения. Кнопка гасила действие браузера, но не всплытие
  события, и до панели оно доходило. Ошибка была ещё в 0.7.2, а прогон её
  пропускал, потому что читал первое меню в списке, а первым оказывалось чужое.

### Проверено

- 484 юнит-проверки в 40 файлах и 53 прогона на живом приложении; в CI теперь
  десять из них, включая «кто ждёт», пол под автопилотом и здоровье
  MCP-серверов.
- Отдельный живой прогон на настоящем конфиге (`npm run qa:tools-live`):
  проверяет, что на экране нет ни ключей, ни заголовков, а команда входа
  копируется рабочей — имя `claude.ai Notion` с пробелом берётся в кавычки.

## 0.7.2 — «Позывной» (2026-08-02)

### Добавлено

- **Своя модель распознавания — с диска.** Встроенный список закрыт намеренно:
  скачанный файл уходит в нативный движок, поэтому поле «вставь ссылку» было бы
  способом выполнить чужой код. Но следствие неудобное — чтобы поставить,
  скажем, мультиязычный Whisper, приходилось ждать релиза Зари.

  Теперь можно показать Заре папку, которая уже лежит на машине. **Настройки →
  Голос → Указать папку…**: она опознаёт, что внутри (whisper, transducer,
  moonshine, nemo-ctc, sense-voice, paraformer, zipformer, dolphin, canary,
  fire-red), показывает модель в том же списке с пометкой «своя» и диктует ею
  наравне со встроенными. Ничего не копируется — файлы остаются там, где лежат.

  Чего Заря не делает — так это не гадает. Одинокий `model.onnx` в папке с
  ничего не говорящим именем выглядит одинаково у шести разных семейств;
  догадка собрала бы движок, который выдаёт мусор, а виновата была бы «плохая
  модель». Вместо этого — отказ, который говорит, что делать: положите рядом
  `zarya-model.json`, и рядом кнопка, копирующая образец.

  Путь приходит только из системного диалога, который открывает главный
  процесс: канал принимает команду «спроси человека», а не готовый путь. А
  «Убрать» убирает запись, но не файлы — их клала не Заря.

- **Каталог моделей берётся у провайдера живьём.** Пусковой комплекс брал список
  из константы в коде — он устаревал с каждым релизом Anthropic, молча, и не
  показывал Opus 5 тому, кто работает по подписке Claude. Теперь Заря
  спрашивает самого провайдера (`GET /v1/models` у Anthropic и OpenAI,
  `/api/tags` у Ollama) и кеширует ответ: экран открывается мгновенно из кеша,
  живой ответ обновляет его следом. Запрос делает главный процесс — он несёт
  ключ; адрес берётся из настроек, а не из окна. Без ключа приходит честная
  ошибка и пустой список, а не выдуманный.

- **Новая модель объявляется один раз.** Появился id, которого раньше не было —
  Заря говорит об этом небольшой полосой. Сравнение идёт с ВИДЕННЫМ, а не с
  прошлым ответом: иначе минута плохой сети объявила бы новинкой вчерашние
  модели. Первый каталог запоминается молча, чтобы свежая установка не
  встречала человека окном про каждую модель.

- **Облик уходит от космической программы к рассвету, в честь которого назван.**
  «Заря» и значит рассвет, а рассвет даёт то, чего эпоха дать не может: свет, у
  которого есть направление и время суток. Ведут его две новые темы —
  **«Синий час»** (двадцать минут до восхода; единственное тёплое пятно в окне —
  янтарь, и он означает «сюда уйдёт Enter») и **«Золотой час»** (утро на бумаге,
  для работы в светлой комнате). «Синий час» стал темой по умолчанию.

  Звёздное поле и конструктивистская сетка убраны. Вместо них у окна просто
  появился низ: едва заметный подъём света там, где живёт строка ввода — место,
  из которого человек действует.

  Темы сохранили палитры и потеряли имена космодрома: Космос → Ночь, Восток →
  Угли, Орбита → Иней, Спутник → Пепел, Байконур → Песок, Плакат → Бумага,
  Чертёж → Калька. Никто не теряет выбранную тему.

  Слова следом: «ПУСКОВОЙ КОМПЛЕКС» → «МОДЕЛЬ И УСИЛИЕ», «ПУСК · ПОЕХАЛИ» →
  «ПРИМЕНИТЬ», «ЦЕНТР УПРАВЛЕНИЯ» → «НАСТРОЙКИ», «Экипаж · агенты» → «Агенты»,
  «Борт готов к старту» → «Можно начинать». Подпись бренда стала
  **// ПЕРВЫЙ СВЕТ** — в астрономии это первая рабочая ночь прибора, то есть
  ровно то, чем приложение и является.

  И позывные провайдеров: АНТ-1 / ГПТ-2 / ЛУНА теперь Anthropic / OpenAI /
  Ollama. Это уже не вкус — позывной прячет, КОМУ уходит ваш запрос.

- **Разделы сайдбара сворачиваются.** «Недавние» никто не заводит руками: список
  копится сам и к концу недели закрывает собой открытые терминалы и занятых
  агентов, ради которых сайдбар и открыт. Теперь каждый раздел сворачивается по
  своему заголовку, помнит это между запусками и в свёрнутом виде показывает
  счётчик — иначе он читался бы как пустое место. «Недавние» свёрнуты сразу;
  поиск разворачивает их сам.

### Изменено

- **Усилие называется так же, как в CLI.** «ТЯГА · EFFORT» со ступенями МАЛАЯ /
  СРЕДНЯЯ / ВЫСОКАЯ / СВЕРХ / ФОРСАЖ читалось красиво, но было нашей метафорой
  поверх чужого понятия: в Claude Code и в документации это `effort` со
  значениями low / medium / high / xhigh / max. Человек, сверяющийся с доками,
  держал в голове перевод. Теперь ступени называются **LOW · MEDIUM · HIGH ·
  XHIGH · MAX** одинаково в обоих языках, как имя модели, а заголовок — просто
  EFFORT. Подписи «быстрее» и «умнее» остались: они объясняют направление, а не
  переводят термин.

- **«Открыть папку…» стало «Добавить проект…».** Пункт стоит первым в списке
  проектов, и после него папка оказывается в этом же списке — прежнее название
  описывало половину действия и оставляло новую строку без объяснения.

- **Неактивные панели больше не гаснут.** На светлой теме затемнение
  (brightness 0.66 и opacity 0.62) превращало белый фон в грязно-серый: три
  панели из четырёх выглядели выключенными, хотя в них шла работа. На
  единственный вопрос, ради которого гашение было, — куда уйдёт Enter — уже
  отвечает акцентная рамка.

### Исправлено

- **Неверно опознанная модель распознавания больше не уносит с собой всё
  приложение.** Движок, получив ONNX не той формы, не возвращает ошибку —
  нативная библиотека печатает строку и вызывает `exit(-1)` из рабочего потока. В
  главном процессе это значит, что Заря исчезает: панели, терминалы, агенты и
  несохранённое состояние, без единого слова о причине. А поскольку выбор
  оставался в настройках, следующий запуск умирал так же.

  Теперь своя модель сначала запускается **в отдельном процессе**. Не собралась —
  человек получает слова самого движка (в них обычно назван настоящий формат), и
  ничего не добавляется. Проверено на настоящих весах: Whisper tiny, объявленный
  `senseVoice`, отклоняется словами, а окно остаётся на месте.

- **Опознание папки сверено с настоящими репозиториями.** В канонических папках
  sherpa-onnx лежат две редакции одного файла (`model.onnx` и `model.int8.onnx`)
  — правило «ровно один .onnx» их отвергало, включая ту самую мультиязычную
  sense-voice, ради которой всё затевалось. А «ctc» в имени папки больше не
  считается приметой NeMo: `telespeech-ctc` — другое семейство, которого движок
  не знает вовсе, и догадка означала не плохое распознавание, а падение.

- **`Enter` в окне «введите имя» больше не одобряет команду за ним.** Пока в
  активной панели ждал гейт, переименование стола с нажатием `Enter` на кнопке
  делало два дела: сохраняло имя И разрешало команду, которую человек ещё не
  прочитал. Теперь, пока окно открыто, `Enter` и `Esc` принадлежат ему.

- **Каталог моделей больше не переживает своего провайдера.** Переключение чипа
  оставляло на экране прежний список (модели Claude предлагались как модели
  OpenAI), а отказ провайдера возвращал зашитый в код пресет — ровно тот
  устаревший список, ради замены которого каталог и стали спрашивать живьём.
  Теперь список очищается, а отказ называется отказом.

- **`qa:models` гонял треть того, что обещал.** Дублирующийся ключ в
  `package.json` молча перекрыл два прогона (`qa-claude-catalog`,
  `qa-model-refresh`) — JSON оставляет последний. Восстановлено; заодно
  `qa:fake-agents` теперь собирает приложение, как все остальные прогоны.

Мелочи из того же ревью: отсутствующий ключ `common.close` показывал сам ключ в
подсказке; полоса «появилась новая модель» лежала под перехватчиком пускового
комплекса; список виденного мог выбросить модель, которая всё ещё в каталоге, и
объявить её новой второй раз; папка модели в корне диска оставалась без имени;
манифест искался без учёта регистра, а читался строчными (Linux); список файлов
обрезался раньше, чем в нём искали манифест.


- **Переименование снова работает.** Нажатие на карандаш у рабочего стола не
  делало *ничего*: Electron не реализует `window.prompt`, а на нём держались
  семь мест интерфейса — переименование стола (кнопка и двойной клик), панели,
  сохранённой сессии, создание файла и папки, переименование файла в дереве. Все
  они молча не делали ничего: не ошибка на экране, а тишина — худший вид
  неправды, какой бывает в интерфейсе. Теперь у Зари своё окно: то же обещание
  «введите имя», но выполненное.

- **Режим панели переживает перезапуск.** Он жил только в памяти окна:
  поработал в Claude Code, перезапустил — и оказался в оболочке, ничего не
  выбирая. Теперь режим хранится в снапшоте сессии и возвращается вместе с ней.

- **Пусковой комплекс открывается на ветке той панели, на которую вы смотрите.**
  Он читал общее умолчание окна, а не режим панели: после перезапуска выходило
  так, что в панели идёт Claude Code — строка ввода подписана им же, — а комплекс
  предлагает аккаунты и модели встроенного борта. Нажатие «ПУСК» применило бы
  выбор не туда, куда человек смотрит.

- **Панель держит тот движок, с которым родилась.** Пока у панели не было своей
  записи, она следовала общему умолчанию окна — а его меняет переключение в

  не трогал, молча переезжали следом. Новая панель по-прежнему открывается «как
  последняя», но дальше живёт своей жизнью: Claude Code в одной панели и Codex в
  соседней остаются на местах.

## 0.7.1 — «Отсчёт» (2026-07-31)

### Добавлено

- **Видно, что работа идёт.** Агент уходил качать репозиторий, и экран замолкал:
  карточка инструмента показывала спиннер и слово «выполняется» — ни секунды, ни
  строчки вывода. Понять, идёт это минуту или десять, было нельзя.

  Теперь карточка тикает: **выполняется · 1:24**. Работает для всех движков,
  включая Claude Code, потому что время старта — единственное, что мы честно
  знаем: вывод инструмента SDK отдаёт одним куском в конце, промежуточного
  прогресса там нет вовсе (`include_partial_messages` стримит текст ответа и
  размышления, но не вывод инструмента). Отсчёт идёт с **одобрения**, а не с
  появления гейта: пока карточка ждёт решения, время идёт у человека, а не у
  команды.

- **Строка скачивания для команд, идущих через терминал.** Загрузчики
  (`git clone`, `pip`, `wget`, `docker pull`) пишут прогресс одной
  перерисовываемой строкой; в терминале это читается, в ленте превращалось в
  прыгающие цифры. Теперь из вывода достаются процент, объём, скорость и ETA — и
  показываются полосой на одном месте.

  Разбор нарочно придирчив: одного процента мало, нужен второй признак —
  скорость, объём, полоса или имя работы, — иначе отчёт о покрытии со строкой
  `Statements: 100% (42/42)` рисовал бы полосу на пустом месте. Когда процента
  нет, ширину не выдумываем: идёт бегунок, потому что полоса «примерно на треть»
  обещала бы знание, которого у нас нет.

### Изменено

- **Проекты живут в одном месте.** Меню проектов было в двух — в шапке и под
  стрелкой в сайдбаре, — и оба показывали одно и то же, причём в сайдбаре
  беднее. Внутри каждого дублирование продолжалось: «Проекты», «Добавить папку в
  проекты…» и «Недавние папки» — три блока про одно. Отдельный пункт «Добавить
  папку в проекты…» открывал ТО ЖЕ системное окно выбора, что и «Открыть
  папку…», и отличался только тем, что папку не открывал.

  Роли разведены: стрелка в сайдбаре — про то, как завести терминал (три пункта,
  никаких списков); шапка «Проекты» — единственное место, где живут папки. Открыл
  папку — она в списке, свежая сверху; кнопка рядом открывает её панелью, крестик
  убирает. Потолок — 12: при трёх-восьми проектах в работе вытеснение не
  сработает никогда, но список без предела перестаёт быть списком.

### Исправлено

- **Карточка инструмента перестала исчезать в момент одобрения.** У движков без
  `tool_use` (Codex, Gemini, Kimi, Qwen) гейт отсеивался как решённый, и после
  нажатия «ВЫПОЛНИТЬ» на экране не оставалось ничего: команда шла минуту, лента
  молчала. Теперь карточка живёт до результата, а подпись «агент хочет
  выполнить» убирается после решения — она сообщала о выборе, которого больше
  нет.
- **Точка «открыто сейчас» перестала врать.** Пути сравнивались посимвольно, а
  до одной папки они приходят в разном виде: диалог выбора отдаёт путь с
  обратными слэшами, оболочка сообщает с прямыми. Сравнение теперь по смыслу, с
  оглядкой на платформу: регистр игнорируется только у путей с буквой диска,
  потому что на Linux `~/Code` и `~/code` — разные папки.
- **Пустой снимок вывода больше не стирает то, что уже видно** — лента мигала
  пустым местом, пока команда ещё шла.

### Проверено

- `npm run qa:progress` — 16 живых проверок: полоса, её обновление, бегунок без
  процентов, молчание на обычном выводе, тикающее время, карточка после
  одобрения. Плюс 15 юнит-тестов на разбор строки прогресса и 9 на список

## 0.6.0 — «Сетка» (2026-07-31)

### Добавлено

- **Каждая панель — самостоятельный CLI.** Раньше окно делилось надвое, но
  разговор, строка ввода, лента и режим были общими: две панели показывали одну
  беседу, а один Enter мог одобрить запуск команды сразу в нескольких. Теперь у
  панели своя лента, своя строка ввода, свой режим и свой автопилот, а клавиши
  раздаёт единый диспетчер — ровно одному адресату. Активная панель обведена
  рамкой, и эта рамка означает буквально одно: сюда уйдут Enter и Esc.

  Раскладка выбирается по числу панелей: одна — во весь экран, две-три —
  колонками, четыре — сетка 2×2. Пятая уходит новой вкладкой: больше четырёх в
  одной вкладке не показываем, потому что на пяти лента превращается в пять
  строк и упирается это молча.

- **Панели активной вкладки — строками в сайдбаре.** «Открытые» перечисляли
  вкладки: четыре панели давали одну строку с припиской «· 4», и попасть мышью в
  конкретную панель было нельзя. Теперь активная вкладка раскрыта панелями,
  остальные — свёрнутыми строками со счётчиком. Две степени выделения не
  путаются: «на экране» (панель видна) и «в фокусе» (панели достаются Enter и
  Esc, такая ровно одна, и метится она тем же акцентом, что рамка на экране).

  Двойной клик по строке разворачивает панель на всю вкладку и возвращает
  обратно; соседи при этом живы и просто не видны.

- **Панель можно перенести и вынести.** Панель хватается за свою шапку: бросок
  на другую панель переносит её туда, бросок в список слева выносит в отдельный
  рабочий стол. Процесс не трогается ни в том, ни в другом случае — раньше убрать
  лишний CLI с разделённого экрана можно было только закрыв его, то есть убив.

- **У рабочего стола есть имя.** Группировка и была вкладкой, но подписывалась
  именем той панели, что в ней активна: четыре разных проекта — одно имя, да ещё
  и меняющееся. Теперь имя собирается из панелей («Заря + quiz-funnel +2») и
  переименовывается двойным кликом.

- **Картинки — в свою панель.** Ctrl+V и перетаскивание кладут изображение в ту
  панель, где стоит курсор, показывают чипом до отправки и уменьшают до предела
  модели. Движок, который картинок не принимает, говорит об этом вслух, а не
  проглатывает вложение молча.

### Исправлено

- **Панель теряла экран при перестройке раскладки.** Место панели в разметке
  зависело от места в дереве: стоило закрыть одну из четырёх, соседняя переезжала
  на другой уровень, и её терминал создавался заново. Заметить это почти нельзя —
  оболочка перерисовывает видимую часть, — но прокрутка и вывод агента исчезали.
  Теперь дерево задаёт только координаты, панель живёт в списке по своей сессии и
  переживает любую перестройку, переезд в другую вкладку и разворот.

- **Пятая панель уходила в никуда**: заводилась живая сессия, которой не было
  места в дереве, — терминал работал, в списке не значился, а Enter и Esc
  адресовались именно ему.

- **Закрытие панели не спрашивало и не убирало за собой.** Теперь оно
  предупреждает о том, что пропадёт (недописанный запрос, ожидающее решение
  агента, идущий ход), гасит гейт и прерывает ход, чтобы счётчик «ждут решения»
  не застревал навсегда, и чистит следы: вложения и автопилот мёртвой панели
  больше не воскресают при восстановлении сессии.

- **Esc из чужого поля ввода прерывал работу панели** — например тот, которым
  бросают поиск сессий в сайдбаре.

- **Режим строки и история ↑ были общими на окно.** Агент, начавший ход в
  соседней панели, переключал чип здесь, и Enter уводил набранную команду
  терминала в модель. Стрелка вверх доставала команду чужого проекта и выполняла
  её в другой папке. И то, и другое теперь принадлежит панели.

- **Микрофон** держится одним замком на приложение: четыре панели больше не
  открывают четыре записи одной фразы, а диктовка уходит в ту панель, где курсор.

## 0.5.8 — «Печать» (2026-07-29)

### Добавлено

- **Подпись релизов.** Установка одним нажатием теперь требует подписи: список
  контрольных сумм каждого релиза подписывается Ed25519-ключом, которого нет в
  CI — он живёт на машине мейнтейнера. Приложение проверяет обе вещи: подпись
  списка сходится с зашитым открытым ключом И sha256 скачанного файла совпадает
  со строкой в этом списке. Не сошлось — файл удаляется, установка отменяется.

  Зачем: до сих пор вся цепочка держалась на том, что CI ручается сам за себя.
  `latest.yml` и `SHA256SUMS` считает та же машина, что и собирает, — при захвате
  конвейера хеш был бы валидным, потому что его посчитала бы уже подменённая
  сборка. С автообновлением это тихое выполнение кода у всех, без единого клика.

  Релиз без подписи не прячется: он виден, его можно скачать вручную, и
  приложение прямо говорит, почему не ставит само. Это **не** Authenticode —
  SmartScreen при ручной установке предупреждать не перестанет; закрывается
  подмена обновления, а не предупреждение Windows.

### Изменено

- **Esc над отправленным сообщением убирает его и из памяти агента.** Раньше
  сообщение оставалось в ленте с пометкой «прервано», и агент видел его на
  следующем ходу. Теперь оно исчезает и возвращается в строку ввода — как в
  настоящем Claude Code.

  Механизм оттуда же: транскрипты CLI — не журнал, а дерево, и отмена продолжает
  беседу от РОДИТЕЛЯ отменённой записи. Agent SDK даёт ровно это
  (`resumeSessionAt` + `forkSession`): следующий ход уходит веткой от последнего
  ответа агента, отменённое остаётся в файле мёртвой веткой.

  Работает это только с Claude Code. У Codex и ACP-движков такого механизма нет —
  там сообщение по-прежнему остаётся с пометкой «прервано», и это честно: убрать
  с глаз то, что агент помнит, было бы враньём.

### Исправлено

- **Ответ на отменённое сообщение больше не долетает в ленту.** Прерванная
  сессия успевала договорить, и её ответ появлялся уже после того, как вопрос
  исчез.
- **Второй Esc подряд не помечает «прервано» уже отвеченный ход.** Первый ещё
  летел по IPC, беседа в это мгновение выглядела незанятой, и метка садилась на
  предыдущий, честно отвеченный вопрос.
- **Обводка иконки папки** в панели слева — два пикселя, как у соседей; была
  заметно тоньше остальных.

## 0.5.7 — «Слово» (2026-07-28)

### Добавлено

- **Выбор модели распознавания.** Модель была захардкожена одной константой —
  теперь это закрытый реестр: **GigaAM v3** (русский, 225 МБ), **GigaAM v3

  Список остался **закрытым**: настраиваемый адрес модели был бы примитивом
  «скачай что угодно откуда угодно», а скачанное отдаётся нативному движку.

### Исправлено

- **Диктовка теперь умеет цифры, латиницу и знаки препинания.** У прежней модели
  словарь состоял из 34 токенов: пробел и 33 строчные русские буквы. Ни цифр, ни
  латиницы, ни заглавных — то есть продиктовать «git commit» или «cd 2» было
  физически невозможно. В новой 257 токенов. Прежняя модель продолжает работать:
  ничего не качается само, обновление предлагается кнопкой.
- **Иконки в панели слева одного размера.** Стояли глифы 16×16 рядом с 8×8 —
  «папка» и «обновление» рисовались вдвое мельче соседей.
- **На странице обновления только нужные файлы.** Служебные `latest*.yml` и
  `.blockmap`, поехавшие в релизы с 0.5.5, попадали в список наравне со
  сборками: одиннадцать строк там, где полезны две. Сборки для чужих систем
  убраны под кат.
- **Обновление убирает за собой.** После установки в кеше оставались две копии
  установщика — 382 МБ, и так после каждого обновления. Чистится при запуске, и
  только то, что старше установленной версии: скачанное, но ещё не поставленное
  обновление не трогается.

## 0.5.5 — «Шаг» (2026-07-28)

### Добавлено

- **Обновление в одно нажатие.** Раньше «обновиться» значило: открыть браузер,
  скачать 190 МБ, сверить хеш руками (чего никто не делает), пройти мастер
  установки. Теперь — кнопка «Установить обновление», полоса скачивания прямо в
  ней и «Перезапустить и установить». Целостность проверяется автоматически по
  sha512 из метаданных релиза.

  Что **не** делается: скачивание и установка в фоне. `autoDownload` и
  `autoInstallOnAppQuit` выключены явно — разница между «нажал кнопку» и «оно
  само подменило исполняемый файл, пока ты работал» принципиальна, тем более для
  неподписанной сборки.

  Установка идёт через штатный выход: рендерер снимает сессии, настройки
  сбрасываются на диск, pty и агенты гасятся — и только потом запускается
  установщик. Обновление не должно стоить открытых терминалов.

  Платформы разделены честно: Windows — да; Linux — только AppImage (`.deb`
  ставится менеджером пакетов); macOS — нет, Squirrel.Mac требует подписи и
  нотаризации. Где нельзя — кнопки нет, и текст объясняет почему. Ручной путь с
  файлами и SHA256 никуда не делся.

### Исправлено

- **Релизы не содержали `latest.yml`.** В конфигурации стоял `publish: null`,
  поэтому метаданные обновления не генерировались вовсе. Теперь они собираются и
  выкладываются вместе с дистрибутивами, а публикация падает, если их нет: релиз
  без метаданных выглядит нормальным, но молча ломает обновление у всех, кто уже
  поставил приложение.
- **Источник обновления задан явной константой** (`setFeedURL`), редиректы при
  проверке ограничены списком хостов GitHub, а в настройках виден возраст
  последней удачной проверки — молчащий прокси может бесконечно отвечать «у вас
  последняя версия», и без даты это неотличимо от правды.

## 0.5.4 — «Затвор» (2026-07-28)

Релиз про то, чтобы интерфейс не успокаивал там, где успокаивать нечем, и не
терял то, что показывает.

### Исправлено

- **Разовое «ВЫПОЛНИТЬ» больше не становится постоянным разрешением.** Часть
  ACP-агентов не предлагает разового разрешения — только `allow_always`. Драйвер
  молча подставлял его на обычное одобрение: человек имел в виду один запуск, а
  агент получал разрешение на всю сессию и переставал спрашивать. Ни в
  интерфейсе, ни в ответе об этом не было ни слова. Теперь такой гейт помечен,
  кнопка называется «РАЗРЕШИТЬ ВСЕГДА» и предупреждает цветом, а постоянное
  разрешение уходит агенту только с явным согласием. Отказ по-прежнему
  повышается свободно: «всегда отклонять» строже разового.
- **Бейдж над API-ключом говорит правду.** Раньше он был один на все случаи —
  зелёное «Ключ сохранён» и над ключом в хранилище ОС, и над ключом, лежащим в
  `secrets.json` открытым текстом. Состояний стало три, с объяснением прямо в
  строке. Защита считается по двум обстоятельствам сразу: как ключ записан и что
  система умеет сейчас — на Linux без keyring `encryptString` ставит `enc:`, не
  защищая ничего.
- **Выпадающее меню помещается в окно.** Список сессий (до 25 строк с длинными
  заголовками) вылезал за кромку, причём за ВЕРХНЮЮ: позиция клампилась только с
  одной стороны, и верхние пункты становились недоступны вообще. Теперь потолок
  высоты с прокруткой, кламп с обеих сторон, строка на пункт с подсказкой
  полного текста. Молчаливое усечение списка до 25 названо вслух.
- **Повторное нажатие по кнопке закрывает попап, а не мигает им.** Панель
  расхода и меню закрывались по `mousedown`, а кнопки переключались по `click`:
  первое событие закрывало, второе тут же открывало заново.
- **Esc закрывает меню, даже когда фокус в терминале.** xterm вешает свой
  обработчик в фазе захвата и глушит Escape — до слушателя меню событие не
  доходило вовсе.
- **Права на файлы данных сужены до `0600`** (каталог — `0700`). В `userData`
  лежат ключи провайдеров, история команд и переписки с агентом; Node создавал
  их с правами по умолчанию, на Linux это 0644. Файлы, созданные прошлыми
  версиями, чинятся отдельно: `history.jsonl` только дописывается и сам никогда
  не пересоздаётся.

### Добавлено

- **История команд под контролем.** Файл рос без ограничений, выключить запись
  было нельзя, стереть тоже — а команды регулярно содержат секреты. Появились
  выключатель (срабатывает немедленно; при выключенной записи история не
  читается с диска вовсе), потолок «хранить не больше N» с уплотнением самого
  файла и кнопка очистки рядом со строкой о том, сколько накоплено.

- **Страница релиза публикуется автоматически** вместе с контрольными суммами,

  устаревшие настройки, и первая же диктовка после смены устройства шла в

- **Микрофон оставался открытым навсегда**, если бар уходил с экрана посреди

- **Шаги субагентов больше не засоряют ленту** — они приходят помеченными

  красным «process exited with code 1». Codex и ACP всегда прерывали только ход;
  теперь семантика одна на все борта. Сообщение, отправленное сразу после Esc,
  больше не теряется молча в закрытой очереди, а прерванный ход помечается
  «прервано»: ответа не будет, но агент увидит его при возобновлении сессии.
- **Настройки шрифта доходят до того, что видно.** «Размер шрифта»,
  «Межстрочный интервал» и «Отступы терминала» уходили только в xterm, который в
  режиме «Блоки» рисуется за кадром, — на экране не менялось ничего. Теперь ими
  управляется и лента. Ответ агента набран другим шрифтом, чем реплика
  пользователя, поэтому при равных пикселях выглядел мельче — размеры выровнены
  оптически.
- **Иконка приложения перестала мылиться.** В `.ico` было четыре размера, и 48px
  (тот, что берёт рабочий стол) оказался уменьшенной копией 256px. Теперь десять
  нативных размеров, включая 96px для крупных значков.

### Безопасность

Продолжение разбора того же аудита — MEDIUM-находки про гейт одобрения.

- **«Автоподтверждение команд» больше не снимает гейт с правки файлов.** Настройка
  задумана для встроенного борта Зари и его единственного инструмента
  `run_command`, но передавалась и нативным драйверам как
  `permissionMode: 'acceptEdits'` — это собственный режим Claude Agent SDK
  «auto-accept file edit operations». Правки Write/Edit проходили **ниже**
  `canUseTool`, то есть мимо всей системы одобрения приложения, при этом
  «АВТОПИЛОТ» был выключен, а чип в баре уверял, что борт спрашивает. Теперь
  нативным драйверам всегда уходит `permissionMode: 'default'`; ослабить гейт
  можно ровно одним явным переключателем — «АВТОПИЛОТ»
  (`src/renderer/src/features/ai/aiStore.ts`, `src/shared/types.ts`).
- **Карточка одобрения больше не прячет то, что просит одобрить.** Длинная или
  многострочная команда сворачивалась до первых 88 символов первой строки —
  опасная часть (`&& rm -rf …`, вторая и третья строки) оставалась под
  сворачиванием, пока «ВЫПОЛНИТЬ» и Enter были в одно нажатие. Пока гейт ждёт
  решения, команда закреплена целиком в отдельном блоке: свернуть нельзя, обрезки
  нет, внутреннего скролла, прячущего хвост, — тоже, многострочность подписана
  счётчиком строк. Строке заголовка текст не доверяем: она делит одну строку с
  подписью инструмента и обрезается примерно на половине порога, так что решение
  «по длине» оставляло полосу команд, срезанных вёрсткой без возможности
  развернуть. Лента при этом прокручивается к ждущему гейту — Enter одобряет из
  любого места окна, поэтому карточка за краем экрана была бы тем же слепым «да».
  После решения карточка снова сворачивается: это уже история, а не выбор
  (`src/renderer/src/features/ai/gates.ts`,
  `src/renderer/src/components/MissionFeed.tsx`, `tests/gates.test.ts`).
- **Чип режима больше не молчит и не врёт.** В режиме встроенного борта чипа не
  было вовсе — включённое автоподтверждение выглядело неотличимо от ручного
  режима. У Gemini/Kimi/Qwen, наоборот, рисовался живой переключатель
  «АВТОПИЛОТ», который физически ничего не делал (`setBypass()` — заглушка, эти
  борта спрашивают всегда). Теперь чип есть во всех агентских режимах и
  показывает тот переключатель, который реально управляет активным бортом, а у
  бортов без bypass он заперт на «РУЧНОЙ». Пока возможности драйверов ещё не
  загрузились, чип показывает настройку, которая реально уйдёт в драйвер, а не
  «автопилот не поддерживается» (`src/renderer/src/components/AgentBar.tsx`,
  `src/main/acpDriver.ts`).
- **Песочница Codex больше не снимает гейт в обход «АВТОПИЛОТА».** Тред
  открывался с `sandbox: 'workspaceWrite'` намертво, а `on-request` в такой связке
  спрашивает только про то, что выходит ЗА песочницу: правку внутри открытой папки
  Codex одобрял сам, без запроса, без карточки и без следа в ленте, пока чип
  показывал «РУЧНОЙ». Теперь песочница следует тому же переключателю, что и
  политика одобрения; при расхождении с той, с которой открыт тред, уходит
  оверрайд на ход — иначе выключение автопилота посреди разговора оставляло тред
  писабельным. Оверрайд шлётся только при расхождении: он заменяет политику
  целиком, и на каждом ходу затирал бы пользовательский
  `[sandbox_workspace_write]` из `~/.codex/config.toml` (`src/main/codexDriver.ts`).
- **Карточка правки в Codex называет файлы.** Запрос на одобрение патча не несёт
  пути — они приходят отдельным событием, и карточка показывала безликое
  «Изменение файлов». После перевода песочницы в read-only через этот гейт пошли
  ВСЕ правки внутри проекта, так что правка `src/` стала неотличима от правки
  `~/.codex/config.toml` — а частый безымянный гейт как раз и вырабатывает слепое
  «Enter». Пути запоминаются из `item/started` и попадают в подпись; когда пути нет
  вовсе, карточка так и говорит, вместо уверенной константы
  (`src/main/codexDriver.ts`, `src/main/codexProtocol.ts`,
  `scripts/mock-codex-app-server.mjs`).
- **Лента ведёт к тому гейту, который одобрит Enter.** Прокрутка шла в конец
  ленты, а Enter одобряет ПЕРВЫЙ неулаженный гейт: при параллельных вызовах
  инструментов на экране оказывалась одна карточка, а подтверждалась другая.
  Теперь якорь — сама карточка, и подпись «Enter · Esc» стоит только на ней
  (`src/renderer/src/components/MissionFeed.tsx`,
  `src/renderer/src/features/ai/gates.ts`).
- **Гейты Gemini/Kimi/Qwen перестали быть безымянными.** Эти борта присылают
  человеческое описание только в `displayName`/`input.title`, а карточка в ленте
  собирала подпись без них — и показывала голое «Bash» или «Edit». То есть
  подтверждение команды, текста которой не было на экране вообще. Подпись теперь
  собирается из самого гейта, одинаково в ленте и в панели
  (`src/renderer/src/features/ai/gates.ts`,
  `src/renderer/src/components/MissionFeed.tsx`).
- **Профиль терминала больше не добавляется молча.** `terminal.customProfiles` —
  это список программ, которые приложение запускает, а канал настроек доступен
  из renderer: скомпрометированный renderer мог прописать свой бинарник и
  получить запуск при каждом старте, то есть **персистентность**, переживающую
  перезапуск. Теперь профиль проходит структурную проверку (абсолютный путь к
  существующему файлу, без управляющих символов, ограниченный argv), из
  окружения пропускаются только локаль, таймзона и прокси — по белому списку,
  потому что чёрный не замыкается: `PROMPT_COMMAND`, `PS0`, `BASH_FUNC_*`,
  `PSModulePath`, `HOME` дают исполнение, а наши же скрипты интеграции читают
  `$HOME/.bashrc`. Всё, что начнёт исполняться заново, дополнительно требует
  явного подтверждения с показом пути, аргументов и значений переменных; отказ
  оставляет прежний список. Профиль перепроверяется ещё раз в момент запуска —
  файл настроек правится и руками (`src/main/shellProfileGuard.ts`,
  `src/main/ipc.ts`, `tests/shellProfileGuard.test.ts`).
- **Найденные шеллы резолвятся в абсолютный путь.** WSL-профили держали голое
  `wsl.exe`, а на Windows загрузчик ищет программу сначала в рабочем каталоге
  дочернего процесса — та же ловушка порядка поиска, что уже закрыта для git.
  Заодно найденные профили теперь имеют приоритет над пользовательскими: профиль
  с чужим id (`pwsh`, `cmd`) больше не подменяет системный шелл, на который
  указывает «авто» (`src/main/shellProfiles.ts`).

### Изменено

- **Сборочная цепочка обновлена: electron-builder 24.13.3 → 26.15.3.** Все
  `app-builder-lib < 26.15.0` генерируют AppRun с висящим двоеточием в

### Исправлено

- **Гейт на правку файла в боковой панели больше не пустой.** Панель «IDE-агент»
  подписывала карточку только из `input.command`, поэтому запрос Edit/Write/Read
  показывался как «—»: подтверждение без единого слова о том, что подтверждаешь.
  Подпись теперь общая с главной лентой, и многострочная команда сохраняет
  переводы строк (`src/renderer/src/features/ai/AiPanel.tsx`,
  `src/renderer/src/features/ai/gates.ts`).
- **Иконка на рабочем столе больше не мылится.** Заря рисуется нативно на каждом

  значки» (96px) такого размера не было вовсе: система брала 48 и растягивала.
  Теперь в `.ico` десять нативных размеров (16, 20, 24, 32, 40, 48, 64, 96, 128,
  256), а генератор переписан на Node без Aseprite и без новых зависимостей — он
  сверяется с закоммиченными PNG и отказывается работать при расхождении, так что
  рисунок гарантированно тот же (`scripts/gen-zarya-icon.mjs`, `build/icon.ico`).

## 0.5.1 — «Часовой» (2026-07-25)

A security + freshness release. An adversarial audit of the whole attack surface
(process spawning, the Electron/IPC boundary, approval gates, secrets, supply
chain) turned up four ways untrusted content could act with the app's authority
— all closed here. Separately, newly released Claude models now appear on their
own, without rebuilding or restarting Zarya.

### Безопасность

Found by an adversarial audit of the whole attack surface (process spawning,
Electron/IPC boundary, approval gates, secrets, supply chain).

- **Опасная папка больше не выполняет код просто от того, что её открыли.**
  `git` запускался по голому имени, а рабочим каталогом был любой каталог,
  который пользователь открыл. На Windows libuv резолвит имя программы из cwd
  дочернего процесса **раньше PATH**, поэтому `git.exe`, положенный в репозиторий,
  zip или расшаренную папку, выполнялся в main-процессе — без гейта одобрения и
  без следа в интерфейсе, автоматически при первом же опросе git-панели.
  Воспроизведено экспериментально; `NoDefaultCurrentDirectoryInExePath` не
  спасает. Теперь путь к git резолвится один раз из доверенных мест, а если
  доверенный git не найден — git-функции просто выключаются, без отката на
  голое имя (`src/main/gitService.ts`, `tests/gitExe.test.ts`).
- **Ссылка в ответе агента больше не может увести окно на произвольный `file://`.**
  Навигационный гейт считал своим origin любой `file:` URL, а лента ответов не
  перехватывала клики по ссылкам — относительная ссылка в markdown резолвилась
  относительно нашего же документа и загружала подсунутую локальную страницу с
  полным доступом к preload-API (pty.write, файлы, управление агентом), то есть
  RCE в обход всех гейтов. Теперь разрешён ровно наш документ, а ссылки из ленты
  уходят во внешний браузер (`src/main/index.ts`,
  `src/renderer/src/components/MissionFeed.tsx`).
- **Гейт одобрения больше не бывает невидимым.** Карточка с командой рисовалась
  только из блоков `tool_use`, которые шлёт один Claude Code. У Codex, Gemini,
  Kimi и Qwen запрос прилетал голым событием — карточки не было **нигде**, но
  Enter его исправно одобрял. То есть пользователь подтверждал команду, которую
  не видел. Теперь любой запрос без описания получает свою карточку в ленте и в
  панели (`src/renderer/src/features/ai/gates.ts`).
- **Рабочий каталог сессии больше не подделывается выводом терминала.** Каталог
  отслеживался по OSC 7 / 9;9 / 1337 / 633;P — а это обычный вывод, который
  может напечатать любая программа. Каталог при этом становится рабочим
  каталогом агента и корнем, которым ограничен его доступ к файлам, так что
  подделка молча расширяла песочницу. Интеграция оболочки теперь сообщает
  каталог по приватному каналу с посессионным nonce (в дочерние процессы он не
  попадает), и после первого доверенного сообщения все неподписанные
  игнорируются. Оболочки без интеграции (cmd.exe, свои профили) работают как
  раньше — защита включается сама, без настроек
  (`src/renderer/src/terminal/cwdTrust.ts`).
- **Dev-сервер сверяется по origin, а не по префиксу строки** — префиксная
  проверка принимала `http://localhost:5920@evil.com/` за свой origin.

### Исправлено

- **New Claude models no longer stay invisible.** The model catalog is served by
  the `claude` binary, not by Zarya — so a model released after the build (Opus 5)
  never appeared in the launch console. Three causes, all fixed: the catalog was
  only re-fetched when the cached list was *empty*, `listModels()` returned nothing
  without a live session, and the shipped binary lagged the user's own CLI
  (`src/main/claudeCodeDriver.ts`, `src/renderer/src/components/LaunchPad.tsx`).
- **Fallback model list no longer claims a stale version.** The emergency catalog
  pinned `claude-opus-4-8`, so offline it announced "Opus 4.8" while the CLI would
  actually run Opus 5. Floating aliases are now version-free; the live catalog
  supplies the exact version.
- **Model identity is version-aware.** `sameModel` compared families only, so
  `claude-opus-4-8[1m]` and `claude-opus-5[1m]` were "the same model": a pin left
  over from a previous generation lit up the NEW row while the OLD id was still
  what got launched. Versions (and the 1M variant) must now agree; a pin no
  longer in the catalog surfaces as its own row instead of silently borrowing
  someone else's (`src/renderer/src/features/ai/modelMatch.ts`).
- **Unpinned model now highlights its row.** The resolve ran over the raw
  catalog, where the account `default` entry (a pointer at another model) is
  matched first and then filtered out of the rendered list — so with no explicit
  pin *no* row was marked active even though a model was plainly running.
- **A model picked while another tab was focused now reaches a running session.**
  Follow-up turns re-synced only bypass and dropped `model`/`effort`/`ultracode`,
  so a background session kept its start-time model for the rest of its life.
- **A hung CLI can no longer freeze the catalog until restart.** The session-less
  probe had no deadline: an unresponsive child left the promise pending forever,
  leaking the process and latching the in-flight guards (catalog and fuel poll
  dead until the app restarted). It now races a 20s timeout and always settles.

### Добавлено

- **Newest-binary preference** — Zarya now runs the user's own (self-updating)
  `claude` CLI when it is strictly newer than the bundled one on the same major
  version, so newly released models appear **without rebuilding or restarting**
  the app. Guard rails: never downgrades, never crosses a major version, and
  `ZARYA_CLAUDE_BIN` overrides everything (`src/main/claudeExe.ts`).
- **Session-less catalog + usage fetch** — a throwaway idle query backs both the
  model catalog and the fuel gauge, so both are correct before the first prompt.
- **QA:** `npm run qa:models` — proves the console shows a *dynamic* catalog with
  no live session, and reports whether the bundled binary has fallen behind the
  system one (`scripts/qa-claude-catalog.mjs`, `scripts/qa-model-refresh.mjs`).
  Unit coverage for the binary-choice policy and the terminal-settings mapping
  (`tests/claudeExe.test.ts`, `tests/terminalOptions.test.ts`) — 109 tests.

### Изменено

- Bundled Claude Agent SDK `0.3.217` → `0.3.220` (ships CLI 2.1.220, which knows
  Opus 5).

## 0.5.0 — «Созвездие» (2026-07-24)

A multi-agent release. Zarya is no longer tied to a single AI backend: a driver
abstraction now lets **five native agent engines** live side by side —
Claude Code, **Codex**, **Gemini**, **Kimi** and **Qwen** — each a chip in the
command bar, each with its own tool-approval gates and resume. Plus bring-your-own-key
presets for Kimi/Qwen/DeepSeek and macOS packaging.

### Добавлено

- **AgentDriver abstraction** — the AI layer is generalized from a hardcoded
  `engine === 'claude-code'` into an open `AgentDriver` interface + capability
  flags + a driver registry, with generic `agent:*` IPC. The renderer renders
  controls from each engine's declared capabilities (fuel gauge, effort dial,
  model picker, bypass, question widget), so a new engine lights up the right UI
  without touching the renderer (`src/main/agentDriver.ts`, `src/shared/types.ts`).
- **Codex engine** — native driver over `codex app-server` (JSON-RPC/JSONL on
  stdio): threads, streamed turns, live command/patch **approval gates**, resume,
  interrupt, model catalog (`src/main/codexDriver.ts`). Appears as a chip when the
  `codex` CLI is installed.
- **Gemini engine (ACP)** — native driver over `gemini --acp` (Agent Client
  Protocol): sessions, streamed chunks, a single unified permission gate, resume,
  interrupt, and a **filesystem proxy confined to the session's working directory**
  (`src/main/acpDriver.ts`).
- **Kimi + Qwen engines** — the same parameterized ACP driver also backs
  `kimi acp` and `qwen --acp`, so both Chinese frontier coding models run natively
  with zero extra transport code. (Qwen's ACP is upstream-experimental.)
- **Bring-your-own-key presets** — the OpenAI-compatible provider gains one-click
  baseURL presets for **Kimi (Moonshot)**, **Qwen (DashScope)** and **DeepSeek** in
  Settings → AI; model ids are typed in (they rotate often). See `docs/ai.md`.
- **macOS packaging** — the Claude Code SDK's platform CLI is unpacked for every
  platform (win/mac-arm/mac-x64/linux), so builds run outside the asar on macOS.

### Безопасность

- **fs-proxy confinement (ACP)** — agent-driven file reads/writes are restricted
  to the session working directory both lexically **and** after resolving symlinks
  (a junction/symlink inside cwd can't escape); untrusted paths that aren't strings
  can't crash the main process.
- **Hardened stdio transports** — bounded JSONL decoder (a runaway line can't OOM
  main), fail-closed tool approvals, request timeouts, and clean teardown of child
  processes on every quit path, across the Codex and ACP drivers.

### Проверено

- 80 unit tests + offscreen harnesses covering each driver end-to-end against a
  protocol-accurate mock server (init, streaming, approve/deny, resume, interrupt,
  fs-proxy + traversal, crash/recovery, quit teardown). Every increment was
  reviewed adversarially before landing.

### Изменено

- **Default theme** is now `zarya-cosmos` (Заря · Космос).
- **Exit-code badges, block separators and command blocks** restyled to match the
  new console aesthetic (behaviour unchanged).
- **Prepare-quit safety timer** raised from 2s to **8s** so session
  snapshot/prune has realistic room to finish on quit instead of being cut off
  mid-write (`src/main/index.ts`).

### Безопасность

- **Prompt-injection spotlighting (OWASP LLM01)** — recent terminal output attached
  as automatic AI context is now wrapped in explicit `<untrusted-terminal-output>`
  markers in the system prompt, with an instruction to treat it strictly as data and
  never as instructions; a payload that forges the closing marker is neutralized
  (`src/renderer/src/features/ai/aiStore.ts`).
- **Navigation hardening** — `will-navigate` **and** `will-redirect` on the main
  window are now guarded: any off-origin navigation of the top frame is blocked and
  `http(s)` URLs are routed to the system browser instead, so the `window.zarya`
  bridge can never be exposed to a remote page (`src/main/index.ts`).
- **Isolated-instance override** — `ZARYA_USER_DATA` points a throwaway instance
  (used by the QA harness) at its own `userData` and bypasses the single-instance
  lock, so visual QA never touches the user's real sessions or settings.

## 0.1.0 (2026-07-20)

Initial release.

### Добавлено

- **Terminal core** — xterm.js 6 with WebGL rendering (DOM fallback on context loss),
  find-in-terminal, clickable web links, Unicode 11 support, per-pane split/tab layout
  with drag-resizable gutters.
- **Blocks** — Warp-style command blocks driven by the OSC 133 shell-integration
  standard: per-command output capture, exit-code badges, duration, re-run, copy
  command/output, export as Markdown, and `Ctrl+↑`/`Ctrl+↓` navigation between blocks.
- **Shell integration** — bundled PowerShell (5.1 & 7+), bash and zsh integration
  scripts emitting OSC 133 (A/B/C/D), OSC 7/9;9/1337 (cwd), and a private,
  nonce-signed OSC 6973 channel for exact command-line capture; auto-detected shell
  profiles plus support for user-defined custom profiles.
- **Persistent sessions** — autosaved scrollback + blocks on an interval and on a
  graceful prepare-quit handshake; pin/favorite sessions; restore replays scrollback
  and blocks then starts a fresh shell in the saved directory; workspace (tabs +
  splits) restore on launch; 200-session prune policy exempting pinned/favorites.
- **AI Assistant** — provider-agnostic streaming transport (Anthropic, OpenAI, Ollama,
  any OpenAI-compatible endpoint) with the actual HTTP calls made from the main
  process so keys never cross into the renderer; encrypted key storage via
  `safeStorage`; tool-calling-capable agent transport with an explicit,
  off-by-default `autoApprove` safety gate; inline natural-language-to-command bar;
  per-block "ask AI" action.
- **Time Machine** — append-only, cross-session global command history with
  fuzzy multi-token search.
- **Workflows** — parameterized, reusable command snippets with `{{param}}`
  templating, user-defined plus a bundled starter pack mechanism.
- **IDE-lite** — Monaco-based editor pane, file tree, git diff view (porcelain v2
  status + HEAD-vs-working-tree diff), and click-to-open for file paths detected in
  terminal output (with `:line[:col]` suffix support).
- **Command palette & keybindings** — a single action registry drives both a
  searchable command palette and a fully remappable, JSON-configurable keybinding map.
- **Themes** — a CSS-variable + xterm-palette theme engine (`ThemeDef`) shipping
  Zarya Dawn and Zarya Night, with a `registerThemes()` extension point for adding
  more.
- **Ghost autosuggest** — fish-style inline command suggestions from cross-session
  history, accepted with `→`.
- **Privacy by construction** — no telemetry, no account, no server component; all
  state lives under the OS `userData` directory; API keys encrypted at rest via the
  OS keychain (Windows DPAPI / macOS Keychain / Linux Secret Service).
